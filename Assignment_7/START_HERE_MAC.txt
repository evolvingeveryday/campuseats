START HERE (MAC)

Option A - Docker Desktop (recommended if MySQL is not installed)
1. Install Node.js 20+ and Docker Desktop.
2. Open Terminal in this extracted folder.
3. Run:
   cp .env.example .env
   docker compose up -d db
   npm install
   npm start
4. Open http://localhost:4000

Option B - Local MySQL already installed
1. Start MySQL.
2. Run: mysql -u root -p < schema.sql
3. Copy .env.example to .env and adjust DB_USER / DB_PASSWORD.
4. Run: npm install && npm start
5. Open http://localhost:4000

GraphQL endpoint: http://localhost:4000/graphql
Health check: http://localhost:4000/health
